# 内容文件夹约定

一条片子就是影片目录里的一个子文件夹。默认目录是 `~/Movies/视频项目`。磁盘上的文件是正文、脚本、文章、字幕、封面和发布包的准；插件工具不负责再读一遍这些文件。

## 文件夹

名字是 `YYYY-MM-DD_可读标题`。列出影片目录就能列出所有片子。打开某一期，先列出那个文件夹，再读需要的文件。

## 文件

| 文件 | 含义 |
| --- | --- |
| `topic.md` | 选题笔记 |
| `script.md` | 口播脚本 |
| `演示/<标题>-16x9.html` | Jacky Motion 横屏录制演示 |
| `演示/<标题>-3x4.html` | Jacky Motion 竖屏录制演示 |
| `公众号文章/<标题>.md` | 已转成 Markdown 的文章 |
| `公众号文章/images/` | 文章配图 |
| `publish-package.json` | 发布用的标题和 tags，不写平台长文案 |
| `{标题}.auto-publish.json` | 发布草稿推断 |
| `*.mp4` / `*.mov` | 成片；带 `_subtitled` 的是烧过字幕的 |
| `*.srt` / `*.ass` | 字幕稿 |
| `*_3x4.png` / `*_4x3.png` / `*_16x9.png` | 封面 |

改脚本或选题，直接写对应的 md。不要另存一份到 overlay。

## 插件另外记的东西

`~/.dsh-oil-creator/overlay.json` 只记工作台自己的状态：影片目录路径、创作者档案、工程绑定、手写发布标记、同步到的播放/赞/评、生成任务。不要把正文写进去。
