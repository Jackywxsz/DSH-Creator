# Creator Cockpit 界面方向

## 1. Product Context

这是面向单人创作者的长期桌面工作台。用户会频繁扫描内容进度、决定下一步动作，并在需要制作时回到同一条真实内容。界面应优先支持快速定位、事实核对和低干扰操作。

## 2. Visual Thesis

运营域直接恢复 Creator Cockpit 原版的纸张感、高对比色和硬阴影，不再套用灰色 Harness 卡片皮肤。一级页签仍负责切换工作域，运营侧栏负责定位任务；进入内容域后继续使用 Oil Creator 原有界面。

## 3. Content Plan

第一层是「会话、内容、运营」。进入运营后，左侧依次提供「灵感库、今日推进、档期规划、内容管线、目标追踪、复盘沉淀、设置与备份」。灵感页左侧是黄色快速捕捉区，右侧是可选择的蓝色编号卡片。内容管线按真实制作阶段分成四列，卡片只补运营元数据。详情制作仍通过同一 `contentId` 返回内容页。

## 4. Interaction Model

工作域切换立即生效，不播放整页入场动画。可点击控件保留清晰的 hover、键盘焦点和 100 到 140 毫秒按压反馈。内容行点击后切到内容页并打开同一条详情。加载、空态和错误都在原位置呈现，不用弹窗替代页面状态。

## 5. Layout System

沿用现有三栏壳层。侧栏宽度继续由 Harness 控制；运营中央工作区覆盖会话区域，但不销毁底层会话状态。中央内容最大阅读宽度为 1280px，左右留白随窗口收缩。灵感页采用双栏，内容管线采用四列，目标与知识库使用硬边卡片。主卡片使用 2px 黑边和 6px 黑色硬阴影，小卡片使用 3px 硬阴影。

## 6. Typography

正文沿用系统无衬线字体；展示标题使用 `Arial Black` 与 `PingFang SC` 回退，桌面端允许 32 到 46px。英文 eyebrow 使用全大写、字距 0.16em 和蓝色。分区标题 18 到 24px，正文 12 到 14px。

## 7. Color System

色彩严格取自原版源码基线：纸张 `#f2f1ec`，次级纸张 `#e5e7eb`，白色卡片 `#ffffff`，墨色 `#111111`，主蓝 `#1f5fff`，品牌黄 `#ffdf2b`，成功绿 `#008e67`，警示红 `#ff4054`。运营侧栏和页面 hero 使用品牌黄，编号与主要动作使用主蓝，边框和阴影统一使用墨色。不使用渐变。

## 8. Signature Detail

保留左上角 Jacky Creator 品牌位和现有三域页签。运营态侧栏整体切成黄色，识别点是全局灯泡快捷入口、蓝色编号灵感卡、黄色 hero 和真实内容管线。内容脚本页的运营经验选择区同样使用黄、蓝、黑硬阴影，把已确认的规则与模板送回当前会话，成稿仍写进真实 `script.md`。

## 9. Responsive Behavior

桌面宽屏显示完整汇总和三列状态；较窄窗口把汇总压成两列，把内容状态折成多行。侧栏自动收起时继续使用 Harness 原有窄栏行为。首轮必须在 1280px 和 375px 宽度进行真实浏览器检查，并验证 `prefers-reduced-motion` 下无依赖动画。
